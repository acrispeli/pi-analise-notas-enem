# Notebooks

Esta pasta é destinada às análises exploratórias dos microdados do ENEM.

Os notebooks poderão ser utilizados para:

- compreender a estrutura dos dados;
- verificar qualidade e valores ausentes;
- explorar distribuições das notas;
- testar hipóteses e análises;
- experimentar técnicas de aprendizado de máquina antes de incorporá-las ao código principal.
