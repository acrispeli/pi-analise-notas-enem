# Interface

Aplicativo estático da redação do ENEM. Os indicadores vêm dos JSON agregados em `outputs/json/`. Não há API.

```bash
npm install
npm run dev
npm run build
npm run preview
```

`npm run build` gera `dist/`. A descrição da interface está em `docs/interface.md`. Versionamento e publicação estão em `docs/repositorio.md`.
